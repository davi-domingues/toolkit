# Setup & Configuration

## Create a New Expo Project

```bash
npx create-expo-app@latest my-app --template blank-typescript
cd my-app
```

For an existing project, discover the SDK version from `package.json` (`expo` dependency version → SDK mapping at https://docs.expo.dev/versions/latest/).

## TypeScript (`tsconfig.json`)

```json
{
  "extends": "expo/tsconfig.base",
  "compilerOptions": {
    "strict": true,
    "paths": {
      "@/*": ["./src/*"],
      "@/assets/*": ["./assets/*"]
    }
  },
  "include": ["**/*.ts", "**/*.tsx", ".expo/types/**/*.ts", "expo-env.d.ts"]
}
```

- `@/*` → `./src/*`, `@/assets/*` → `./assets/*`
- `expo-env.d.ts` is auto-generated by Expo; add to `.gitignore`.

## App Config (`app.json`)

Key fields:
- `"scheme"` — deep linking scheme (e.g. `"myapp"` → `myapp://`)
- `"userInterfaceStyle": "automatic"` — enables light/dark mode support
- `"plugins"`: `expo-router` required for file-based routing; `expo-splash-screen` for splash config
- `"experiments.typedRoutes": true` — generates route types
- `"experiments.reactCompiler": true` — enables React Compiler optimizations

## Common Commands

```bash
npm install               # Install dependencies
npx expo start            # Start dev server
npx expo start --ios      # iOS simulator
npx expo start --android  # Android emulator
npx expo start --web      # Browser
npx expo export           # Production build
```
