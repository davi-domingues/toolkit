# Mappers Testing Rules

**Location:** `src/test/java/.../adapter/out/persistence/mapper/`

Mappers (usually generated by MapStruct) convert between Domain Records, Persistence Entities, and API DTOs.

## Core Principles
1. **Real Instances Only**: NEVER mock the mapper you are testing.
2. **Access via INSTANCE**: Obtain the mapper using the MapStruct generated singleton `Mapper.INSTANCE`.
3. **Thorough Field Verification**: Test that all relevant fields map correctly, especially nested objects or collections.

## Rules & Restrictions
- **No Mocks allowed**: Do not use `@ExtendWith(MockitoExtension.class)`. Do not use `@InjectMocks`.
- **Null Handling**: You MUST test how the mapper handles null inputs if it contains specific null-handling logic or `@Mapping` annotations dealing with defaults.
- **Collections/Pages**: If the mapper converts `List` to `List` or Spring `Page` to `Page`, write specific tests to ensure metadata and collection sizes are preserved.

## Generic Skeleton

```java
class <Domain>MapperTest {

    private final <Domain>Mapper mapper = <Domain>Mapper.INSTANCE;

    @Test
    void givenEntity_whenToModel_thenMapAllFieldsCorrectly() {
        <Domain>Entity entity = new <Domain>Entity();
        entity.setId(UUID.randomUUID());
        entity.setName("Value");

        <Domain>Model result = mapper.toModel(entity);

        assertNotNull(result);
        assertEquals(entity.getId(), result.id());
        assertEquals(entity.getName(), result.name());
    }

    @Test
    void givenNullEntity_whenToModel_thenReturnNull() {
        assertNull(mapper.toModel(null));
    }

    @Test
    void givenEntityPage_whenToResponsePage_thenPreserveMetadata() {
        Page<<Domain>Entity> entityPage = new PageImpl<>(List.of(entity1, entity2), Pageable.unpaged(), 2);

        Page<<Domain>Response> result = mapper.toResponsePage(entityPage);

        assertEquals(2, result.getContent().size());
        assertEquals(2, result.getTotalElements());
    }
}
```

In the first test, populate every field the mapping covers and assert each critical one.
